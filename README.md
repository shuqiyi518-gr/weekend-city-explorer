一句话简介
一个帮城市里的年轻人「解决周末去哪」的轻量 Web 应用：输入天气、预算、人数和兴趣，直接给出本周末值得一去的活动；想去但不想一个人去，就顺手组队；去过之后留下一张照片和一句话，成为下一个人的参考。

解决什么问题
周末的痛点从来不是"没有地方可去"，而是"选择太多、决策太累"——要同时权衡天气、预算、同伴人数、通勤距离，还要翻遍小红书和公众号做攻略。这个项目的定位是：把决策成本降到最低，给出不用纠结的周末答案。​

四个核心模块

首页：当日天气卡（温度 / 降雨 / 体感）+ "AI 周末提案"入口，六个兴趣分类（展览、市集、演出、徒步、咖啡、摄影）一键直达，下方是本周末热门活动卡片（含匹配度、价格、地点、时段、热度）。
AI 推荐：预算 / 人数 / 兴趣 / 天气四维筛选器，结果实时随筛选变化，按"兴趣 × 天气 × 预算 × 热度"综合排序，卡片标注匹配度百分比。
组队大厅：按活动发起队伍，写明时间、集合点、人数上限与期待，支持一键加入；侧栏有组队提示与本周人次统计。
打卡分享：上传照片 + 星级评分 + 一句话攻略，发布后进入"大家的周末"信息流，形成 UGC 闭环，配积分激励（+20）。
设计与交互
暖橙 + 米白的"三福"色系，大圆角卡片、玻璃拟态顶栏、轻动画；桌面端四页导航、移动端底部 Tab，响应式在 1440px 容器内自适应。

当前阶段
这是一个可交互的概念原型（Prototype）​：界面、状态流转与交互反馈都已跑通，但活动、队伍、打卡数据为内置演示数据（当前演示城市：东京），尚未接入天气 API、真实活动数据源与账号体系。城市选择、个人档案等入口已预留。

下一步可拓展
接入真实天气与活动数据 API → 用大模型做自然语言提问式推荐（"明天下午想找个不晒的地方待两小时"）→ 用户画像与协同过滤提升匹配度 → 行程自动排期与地图路线 → 队伍聊天与签到。
